      How to read this evidence

      Passing a test can mean failing safely. Expected overflow and mute tests pass when the stream explicitly aborts. A completed handoff is still a failed command if its onset is missing.

      A finite buffer has a finite promise. Capturing continues during delayed acceptance and post-command draining. Only one bounded in-flight packet can protect overwritten bytes; lost data is never recreated.

      These are software semantics. Ring bytes are PCM payload only. Python allocations, DMA, TLS, model memory, embedded CPU, energy and acoustic accuracy are unmeasured.

      Telemetry snapshots: 10 ms. Lifecycle and chunk events: exact source sample indices. Transport acknowledgements are simplified; no real network or speech upload occurs.
